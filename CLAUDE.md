# Project overview

This repository implements a webapp for generating Pilates lesson plans.

# Project structure

The project is split into two main sections:

## Backend (`./backend/`)
- Written in Python and uses the FastAPI web framework
- Work here when you need to: Add API endpoints, implement domain logic, modify data access
- More details: `./backend/CLAUDE.md`

## Frontend (`./frontend/`)
- Written in TypeScript and uses the Next.js React framework
- Work here when you need to: Build UI components, create pages, handle forms
- Integrates with the backend using an API client generated by `hey-api/openapi-ts`
- More details: `./frontend/CLAUDE.md`

# Local development

## Services
- Backend runs on `http://localhost:8000`
- Frontend runs on `http://localhost:3000`

## Making changes to the API
1. Modify backend API endpoints
2. Run backend: `make api` from `./backend/`
3. Generate API client: `pnpm openapi-ts` from `./frontend/`
4. Format API client: `make format` from `./frontend/`
5. Delete the unused `'@ts-expect-error'` directive added by `hey-api` in `./frontend/src/lib/apiClient/client/client.gen.ts`
6. Ensure all checks pass by running `make local_ci` from the project root
7. Commit API client with message: `Auto-update frontend API client using hey-api`


# Git
- This project uses atomic commits
- All linting checks must pass before committing. ALWAYS check this before committing by running `make local_ci`
- Do not add yourself as the co-author for commits
